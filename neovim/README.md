## 42 session

Install Neovim and use a local npm directory:

```bash
mkdir -p ~/.npm-global
npm config set prefix ~/.npm-global
```

Add this export in your `~/.zshrc`:

```bash
export PATH="$HOME/.npm-global/bin:$PATH"
```

## macOS

Install Neovim and Node.js with Homebrew:

```bash
brew install neovim node
```

## Setup `init.lua`

Copy this repository config:

```bash
mkdir -p ~/.config/nvim
cp ./init.lua ~/.config/nvim/init.lua
```

Restart Neovim.

## Add Prettier

Install Prettier globally in your user directory:

```bash
npm install -g prettier
```

## Vim shortcuts

Use the existing shortcuts reference from this repository: [vim/README.md](../vim/README.md).
